## 🌟 Featured Software & Full-Stack Projects

### 1. 🛡️ AssetDesk — Enterprise IT Asset & Service Ticket System
- **Overview:** Full-stack MERN application built to streamline IT asset tracking, hardware lifecycle management, and service desk operations.
- **Architecture:** Clean 4-layer backend architecture (Routes → Controllers → Services → Repositories).
- **Key Features:** Priority SLA calculation engine with live countdown timers, granular RBAC (Admin, Technician, Employee, Auditor), read-only security audit log with change diffs, and Recharts executive dashboards with client-side PDF export.
- **Tech Stack:** React 19, Node.js, Express.js, MongoDB Atlas (Mongoose), TanStack Query, Zustand, Recharts, Tailwind CSS.
- **Links:** [GitHub Repo](https://github.com/Asmithcodes/Ticket-Management-System) • [Live Demo](https://asset-desk.netlify.app/dashboard)

### 2. 🌊 AquaComply India — Environmental Compliance Platform
- **Overview:** AI-powered compliance auditing tool built for Indian water & air quality standards set by CPCB.
- **Key Features:** Automated PDF lab report parsing using PDF.js and Google Gemini API, parameter extraction, and regional compliance validation.
- **Tech Stack:** React, Vite, Google Gemini API, PDF.js, Tailwind CSS.
- **Links:** [Live Demo](https://asmithcodes.github.io/AquaComply-India/)

### 3. 🧠 Lumina — AI Decision-Clarity Engine
- **Overview:** AI-driven psychological decision analysis tool that guides users through complex dilemmas.
- **Key Features:** Structured 5-step clarity reports generated in under 2 seconds, surfacing hidden assumptions and emotional blind spots.
- **Tech Stack:** React, Google Gemini API, JavaScript.
- **Links:** [GitHub Repo](https://github.com/Asmithcodes/Lumina-The-Decision-Engine) • [Live Demo](https://asmithcodes.github.io/Lumina-The-Decision-Engine/)

### 4. 🔊 Acoustic Data Link — Air-Gapped Audio Modem
- **Overview:** Browser-based 8-FSK acoustic data link encoding text and files into audio tones for air-gapped peer-to-peer data transfer over speakers and microphones.
- **Key Features:** Web Audio API signal synthesis, SNR handshake detection, CRC32 integrity verification, and retro signal intelligence UI.
- **Tech Stack:** React, Web Audio API, DSP algorithms.
- **Links:** [GitHub Repo](https://github.com/Asmithcodes/Transmit-via-Sound) • [Live Demo](https://asmithcodes.github.io/Transmit-via-Sound/)
