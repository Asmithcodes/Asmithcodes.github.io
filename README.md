# Asmith Pampana — Portfolio

A modern, interactive portfolio showcasing my work in software development, web applications, and embedded systems.

## About This Portfolio

This portfolio represents my journey as a final-year Electronics and Communication Engineering student with a strong focus on building functional, real-world applications. It highlights my transition from embedded systems and IoT work to full-stack web development, demonstrating a systems-thinking approach to problem-solving.

## Featured Work

### Primary Projects
- **Lumina** — AI-powered decision-clarity tool for complex personal dilemmas
- **AetherWay** — Intelligent travel planning application with real-time multi-modal transport comparison
- **QR A3 Batch Generator** — Proof-of-concept web tool for bulk QR code generation and print layout
- **AI Music Discovery** — Context-aware music recommendation system with Spotify verification

### Systems & Embedded Work
- **IoT & Embedded Prototypes** — Collection of ESP32-based projects including surveillance robots and sensor systems
- **Verilog Programs** — Digital logic and hardware description fundamentals

## Technical Approach

Built with modern web technologies:
- **React + TypeScript** for type-safe component architecture
- **Vite** for fast development and optimized builds
- **Tailwind CSS** for responsive, utility-first styling
- **Framer Motion** for smooth, physics-based animations
- **Interactive backgrounds** and kinetic UI elements for engaging user experience

## Design Philosophy

The portfolio emphasizes:
- **Functional aesthetics** — Visual design that enhances usability without sacrificing clarity
- **Responsive interactions** — Smooth animations and micro-interactions that feel natural
- **Accessibility-first** — Respects user preferences including reduced motion settings
- **Performance** — Optimized for fast load times and smooth rendering
